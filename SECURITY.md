# Security

## Reporting a Vulnerability

If you find a security related bug in Kynomesh, we kindly ask you for
responsible disclosure and for giving us appropriate time to react, analyze and
develop a fix to mitigate the found security vulnerability.

Please report vulnerabilities by e-mail to the following address:

- whynowy@gmail.com

All vulnerabilities and associated information will be treated with full
confidentiality.

## Public Disclosure

Security vulnerabilities will be disclosed via
[release notes](https://github.com/kynoproj/kynomesh/releases) and using the
[GitHub Security Advisories](https://github.com/kynoproj/kynomesh/security/advisories)
feature to keep our community well informed, and will credit you for your
findings (unless you prefer to stay anonymous, of course).
